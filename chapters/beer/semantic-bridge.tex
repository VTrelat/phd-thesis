\section{The B--SMT semantic bridge}
\label{sec:beer-semantic-bridge}

Every correctness statement of this chapter compares a B denotation with an SMT denotation.
This section introduces, once and for all, the canonical constructions that make such comparisons possible: encoding of B types in SMT types, canonical isomorphisms and their associated retractions with the round-trip laws relating them, canonical images of a B-side sets, and the agreement relation \(\semrel\).
All objects live in the ZFC universe of \Cref{ch:zflean}; in particular \(\regnotation{\interpZ{\alpha}}\) denotes the carrier set of a B or SMT type \(\alpha\) (\Cref{def:b-type-interp,def:smt-type-interp}).

\subsection{Encoding B types into SMT types}
\label{sec:beer-type-encoding}
B types are mapped to their SMT counterparts homomorphically, the only non-structural clause being set types: a B set is represented by a \emph{characteristic predicate}, a total Boolean-valued function on the carrier of the element type.

\begin{definition}[B-to-SMT type encoding][B.BType.toSMTType][Encoder/Basic.html\#B.BType.toSMTType]
  \label{def:beer-type-encoding}
  The encoding function \(\regnotation{\toSMT{\cdot}}\) from B types to SMT types is defined recursively by the mappings
  \[
    \begin{aligned}
      \intB                 &\;\mapsto\; \intS, &
      \boolB                &\;\mapsto\; \boolS, \\
      \alpha \prodB \beta   &\;\mapsto\; \toSMT{\alpha} \timesS \toSMT{\beta}, &
      \setB \alpha          &\;\mapsto\; \toSMT{\alpha} \toS \boolS.
    \end{aligned}
  \]
\end{definition}

Two remarks are in order.
First, the encoding never produces \(\optS\) or a function type with a non-Boolean codomain, so a straightforward induction shows \(\mgf{(\toSMT{\alpha})} = \toSMT{\alpha}\): every encoded type is in the \emph{most general}, relational normal form of \Cref{ch:loosening}.
Values known to be functional may nonetheless be manipulated through strictly tighter representations of the same B value; the cast layer of \Cref{sec:beer-rules-cast} relates these intermediate representations to the type encoding above.
Second, different SMT terms may of course denote the same characteristic predicate, but the semantic representation itself is not forgetful: on the carrier \(\interpZ{\toSMT{\alpha}}\), a value is uniquely determined by its B retraction, as the round-trip laws below will show.

\subsection{The indexed family of canonical isomorphisms and associated retractions}
\label{sec:beer-canonical-iso}

The indexed construction is forced by an ambiguity that arises if one first tries to define \(\semrel\) on bare ZF values.
Interpretations of distinct types need not be disjoint; for example,
\[
  U \;\coloneq\; \zop{1}
  \;=\; \pairZ{\topZ}{\emptyset}
  \in \interpZ{\intB} \;\cap\; \interpZ{\boolB \prodB (\setB\intB)}.
\]
Indeed, the chosen ZF encoding represents the integer \(1\) by the Kuratowski pair \(\pairZ{\topZ}{\emptyset}\); its first component is an element of \(\Zbool\), and its second an element of \(\powZ(\Zint)\).
Thus, the same underlying set \(U\) denotes either the integer \(1\) or the pair consisting of Boolean true and the empty set of integers.
This overlap does not make the model ill-defined: \(\BDom\) and \(\SDom\) are dependent sums (\Cref{def:b-dom,def:smt-dom}), so \(\denval{U}[\intB]\) and \(\denval{U}[\boolB \prodB (\setB\intB)]\) are distinct denotation values.
The ambiguity nevertheless appears as soon as one tries to compare the underlying values: at type \(\intB\), the canonical image of \(U\) is \(U\) itself, whereas at type \(\boolB \prodB (\setB\intB)\), it is \(\pairZ{\topZ}{F_{\bot}}\), where \(F_{\bot}\) is the constant-false characteristic predicate on \(\Zint\).

The typing information carried by denotations resolves this ambiguity, and is precisely where the index of the bridge comes from.
What cannot be recovered is which correspondence is intended: the bare set \(U\) alone does not determine which of the two transports above should be used, as depicted in \Cref{fig:beer-indexed-transports}.
We therefore construct two indexed functions \(\canon{\alpha}\) and \(\retr{\alpha}\), so that the intended transport is selected even when another carrier \(\interpZ{\beta}\) overlaps \(\interpZ{\alpha}\); the round-trip laws will then establish \(\retr{\alpha} = \canon{\alpha}^{-1}\) on the corresponding carrier.
The agreement relation \(\semrel\) will be built from exactly this indexed inverse.

\paragraph{Canonical isomorphisms.}
The B-to-SMT type encoding preserves carriers up to ZF isomorphism.
The following theorem establishes existence; the definition immediately afterwards fixes a canonical witness, uniformly and recursively in the B type.

\begin{theorem}[Isomorphism of type interpretations][BType\_iso\_SMTType][SMT/Reasoning/Defs.html\#BType_iso_SMTType]
  \label{thm:beer-btype-iso}
  For every B type \(\alpha\),
  \(
    \interpZ{\alpha} \mathbin{\zop{\cong}} \interpZ{\toSMT{\alpha}}.
  \)
\end{theorem}

\begin{proof}
  By induction on \(\alpha\).
  For \(\intB\) and \(\boolB\), the B and SMT interpretations coincide, so the identity is an isomorphism.
  \begin{fact}
    Isomorphisms are preserved by products:
    \[
      A \mathbin{\zop{\cong}} A' \;\land\; B \mathbin{\zop{\cong}} B' \implies
      A \timesZ B \mathbin{\zop{\cong}} A' \timesZ B'
    \]
  \end{fact}
  \begin{subproof}
    If \(u \in A'^A\) and \(v \in B'^B\) are bijections, then
    \[
      \zop{\lambda} (a,b) \mapsto \pairZ{u(a)}{v(b)} \quad\text{and}\quad \zop{\lambda} (a',b') \mapsto \pairZ{u^{-1}(a')}{v^{-1}(b')}
    \] are two-sided inverses.
  \end{subproof}
  Applying this fact to the two induction isomorphisms gives
  \[
    \begin{aligned}
      \interpZ{\alpha \prodB \beta}
      &\triangleq \interpZ{\alpha} \timesZ \interpZ{\beta} \\
      &\mathbin{\zop{\cong}} \interpZ{\toSMT{\alpha}} \timesZ \interpZ{\toSMT{\beta}} \\
      &= \interpZ{\toSMT{(\alpha \prodB \beta)}}.
    \end{aligned}
  \]
  Finally, the powerset of a carrier is isomorphic to the space of its characteristic predicates.
  \begin{fact}
    Isomorphisms are likewise preserved by function spaces:
    \[
      A \mathbin{\zop{\cong}} A' \;\land\; B \mathbin{\zop{\cong}} B' \implies
      B^A \mathbin{\zop{\cong}} (B')^{A'}
    \]
  \end{fact}
  \begin{subproof}
    For bijections \(u \in A'^A\) and \(v \in B'^B\), use the mutually inverse maps
    \[
      \zop{\lambda} f \mapsto v \fcompZ f \fcompZ u^{-1},
      \quad\text{and}\quad
      \zop{\lambda} g \mapsto v^{-1} \fcompZ g \fcompZ u.
      \vspace*{-\baselineskip}
    \]
  \end{subproof}
  \begin{fact}
    For any set \(A\), \(\powZ(A) \mathbin{\zop{\cong}} {\Zbool}^A\).
  \end{fact}
  \begin{subproof}
    Use \(\zop{\lambda} X \mapsto a \mathbin{\zop{\in}} X\), with inverse
    \(\zop{\lambda} p \mapsto \setcomp{a\in A}{p(a)=\topZ}\).
  \end{subproof}
  Applying these facts to the induction isomorphism on the domain and the identity isomorphism on \(\Zbool\), and composing with the characteristic-predicate isomorphism, gives
  \[
    \begin{aligned}
      \interpZ{\setB\alpha}
      &\triangleq \powZ(\interpZ{\alpha}) \\
      &\mathbin{\zop{\cong}} {\Zbool}^{\interpZ{\alpha}} \\
      &\mathbin{\zop{\cong}} {\Zbool}^{\interpZ{\toSMT{\alpha}}} \\
      &= \interpZ{\toSMT{(\setB\alpha)}}.
    \end{aligned}
    \vspace*{-\baselineskip}
  \]
\end{proof}

\begin{definition}[Canonical isomorphism][BType.canonicalIsoSMTType][SMT/Reasoning/Defs.html\#BType.canonicalIsoSMTType]
  \label{def:beer-canonical-iso}
  For every B type \(\alpha\), we define a set-level function \(\regnotation{\canon{\alpha}} \in {\interpZ{\toSMT{\alpha}}}^{\interpZ{\alpha}}\) by induction on \(\alpha\):
  \begin{align*}
    \canon{\tau} &\;\triangleq\; \Id{\interpZ{\tau}} && \text{for \(\tau \in \{\,\intB, \boolB\,\}\)}, \\
    \appZ\canon{\alpha \prodB \beta}\pairZ{a}{b} &\;\triangleq\; \pairZ{\appZ\canon{\alpha}(a)}{\appZ\canon{\beta}(b)} && \text{for any \(\pairZ{a}{b} \in \interpZ{\alpha \timesS \beta}\)}, \\
    \appZ\canon{\setB \alpha}(\mathcal{D}) &\;\triangleq\;
      \zop{\lambda} w \mapsto
        \appZ\canon{\alpha}^{-1}(w) \mathbin{\zop{\in}} \mathcal{D} && \text{for any \(\mathcal{D} \in \interpZ{\setB \alpha}\)}.
  \end{align*}
\end{definition}

The base cases are identities: B and SMT integers and Booleans share their ZFC encodings.
The product case acts componentwise.
The set case turns a subset \(\mathcal{D} \subseteq \interpZ{\alpha}\) into its characteristic predicate, transported along \(\canon{\alpha}\).
In the definition above, \(\mathbin{\zop{\in}}\) abbreviates set membership cast in the ZFC universe: the predicate answers \(\topZ\) on \(w\) exactly when the \(\canon{\alpha}\)-preimage of \(w\) belongs to \(\mathcal{D}\).
By construction, \((\canon{\alpha})_\alpha\) is a family of bijections and hence a witness of \Cref{thm:beer-btype-iso}; the proof of bijectivity proceeds by the same induction, we therefore refer to the formalization ({\small\leancodeptr{canonicalIsoSMTType}{SMT/Reasoning/Defs.html\#BType.canonicalIsoSMTType}}) rather than reproduce its bookkeeping here.

\paragraph{Retractions.}
By canonicity, \(\canon{\alpha}\) already has an inverse, so introducing a separate family \(\retr{\alpha}\) may at first seem redundant.
The equation \(\retr{\alpha} = (\canon{\alpha})^{-1}\), however, would characterize \(\retr{\alpha}\) only extensionally; it would not exhibit how semantic values are transported at each type constructor.
The soundness argument needs precisely these constructor equations.
At a product type, the transport acts componentwise; at a set type, it maps a characteristic predicate \(\chi\) to the subset on which \(\chi\) is true after its arguments have been transported by \(\canon{\alpha}\).
In particular, for every \(a \in \interpZ{\alpha}\), the set clause directly gives
\[
  a \in \appZ\retr{\setB\alpha}(\chi)
  \iff
  \appZ \chi\bigl(\appZ\canon{\alpha}(a)\bigr) = \topZ,
\]
the equivalence used throughout the membership cases of the soundness proof.
We therefore define \(\retr{\alpha}\) recursively: this exhibits the inverse constructor by constructor and makes its computation rules available to structural proofs.
The round-trip laws then eventually establish that the resulting function is pointwise equal to \((\canon{\alpha})^{-1}\).

\begin{definition}[Retraction][retract][SMT/Reasoning/Defs.html\#retract]
  \label{def:beer-retraction}
  For every B type \(\alpha\), the \emph{retraction} \(\regnotation{\retr{\alpha}} \in {\interpZ{\alpha}}^{\interpZ{\toSMT{\alpha}}}\) of \(\canon{\alpha}\) is defined by induction on \(\alpha\):
  \begin{align*}
    \retr{\tau} &\;\triangleq\; \idZ{\interpZ{\tau}} && \text{for \(\tau \in \{\,\intB, \boolB\,\}\)}, \\
    \appZ\retr{\alpha \prodB \beta}(u) &\;\triangleq\; \pairZ{\appZ\retr{\alpha}(\fstZ u)}{\appZ\retr{\beta}(\sndZ u)}, && \text{for any \(u \in \interpZ{\toSMT{\alpha \prodB \beta}}\)} \\
    \appZ\retr{\setB \alpha}(\chi) &\;\triangleq\; \bigl\{ a \in \interpZ{\alpha} \;\big|\; \appZ \chi\bigl(\appZ\canon{\alpha}(a)\bigr) = \topZ \bigr\} && \text{for any \(\chi \in \interpZ{\toSMT{(\setB\alpha)}}\)}.
  \end{align*}
\end{definition}

On a set type, the retraction recovers the B-level set from a characteristic predicate \(\chi\) by comprehension: it collects those \(a \in \interpZ{\alpha}\) whose canonical image satisfies \(\chi\).
Note the asymmetry with \Cref{def:beer-canonical-iso}: \(\retr{\setB\alpha}\) queries \(\chi\) at \(\canon{\alpha}\)-images and needs no inverse.

\subsection{Round-trip laws}
\label{sec:beer-round-trip}

\begin{theorem}[Round trips][retract\_of\_canonical, canonicalIso\_composition\_retract][SMT/Reasoning/Defs.html\#retract_of_canonical, SMT/Reasoning/Defs.html\#canonicalIso_composition_retract]
  \label{thm:beer-round-trip}
  For every B type \(\alpha\),
  \[
    \retr{\alpha} \fcompZ \canon{\alpha} = \idZ{\interpZ{\alpha}}
    \qquad\text{and}\qquad
    \canon{\alpha} \fcompZ \retr{\alpha} = \idZ{\interpZ{\toSMT{\alpha}}}.
  \]

These are precisely the two facts the soundness proof consumes.
The left identity is used whenever an SMT denotation is, by construction, the canonical image of a B denotation.
The right identity converts a retracted value back into the SMT world; it is what makes \(\retr{\alpha}\) injective and hence lets an SMT-level equality be \emph{reflected} from a B-level one (\Cref{sec:beer-case-pointwise}).

With these identities in hand, we can already assemble the preliminary semantic square of \Cref{fig:beer-type-semantic-square}, a type-level precursor of the full representation-aware square in \Cref{fig:beer-semantic-square}.

\subsection{The canonical image and the bridge lemma}
\label{sec:beer-canonical-image}

The isomorphism defined above lifts from points to sets.

\begin{definition}[Canonical image][BType.canonicalImage][SMT/Reasoning/Defs.html\#BType.canonicalImage]
  \label{def:beer-canonical-image}
  For a B type \(\alpha\) and a set \(\mathcal{D} \subseteq \interpZ{\alpha}\), the \emph{canonical image} of \(\mathcal{D}\) is the set of target values whose retraction belongs to \(\mathcal{D}\):
  \[
    \regnotation{\cimg[\alpha]{\mathcal{D}}} \;\triangleq\; \left\{\, y \in \interpZ{\toSMT{\alpha}} \;\big|\; \retr{\alpha}(y) \in \mathcal{D} \,\right\}.
  \]
\end{definition}

\begin{remark}
  Although the definition introduces \(\cimg[\alpha]{\mathcal{D}}\) as notation for a retraction-based comprehension, it agrees with the usual meaning of direct image (\Cref{def:dom-range-image}).
  Indeed, the round-trip laws make \(\canon{\alpha}\) and \(\retr{\alpha}\) mutual inverses, so
  \[
    \canon{\alpha}[\mathcal{D}] = \retr{\alpha}^{-1}[\mathcal{D}],
  \]
  where the right-hand side denotes the inverse image of \(\mathcal{D}\) under \(\retr{\alpha}\).
  The notation also displays the transporting isomorphism and its type index explicitly, which is important because distinct types may have overlapping ZF interpretations.
\end{remark}

Unfolding \Cref{def:beer-retraction} at a set type yields the elementary fact that does most of the work in \Cref{sec:beer-soundness}.

\begin{lemma}[Bridge lemma][retract][SMT/Reasoning/Defs.html\#retract]
  \label{lem:beer-bridge}
  Let \(\beta\) be a B type and \(\chi \in \interpZ{\toSMT{(\setB\beta)}}\) a characteristic predicate, and define
  \(X \coloneq \appZ\retr{\setB\beta}(\chi)\).
  Then for all \(x \in \interpZ{\beta}\),
  \[
    x \in X \iff \appZ \chi\bigl(\appZ\canon{\beta}(x)\bigr) = \topZ.
  \]
\end{lemma}

\begin{proof}
  Immediate from \Cref{def:beer-retraction}: \(X = \{ x \in \interpZ{\beta} \mid \appZ \chi(\appZ\canon{\beta}(x)) = \topZ \}\), and \(x \in \interpZ{\beta}\) holds by assumption.
\end{proof}

Despite its one-line proof, the lemma deserves its name: it is the canonical instance of the representation-aware membership bridge used throughout the soundness proof.

\subsection{The agreement relation}
\label{sec:beer-agreement}

Recall from \Cref{def:b-dom,def:smt-dom} that B and SMT denotations are triples \(\denval{X}[\alpha]\) packaging a ZF value, a (B or SMT) type, and a proof that the value belongs to the carrier of that type.
The target type need not be the canonical encoding \(\toSMT{\alpha}\).
The order-theoretic account of \Cref{ch:loosening} already describes the possible representations: every type \(\sigma\) selected by the encoder for a B type \(\alpha\) lies in the adjoint interval
\[
  \sigma \in
  \bigl[\lgf{(\toSMT{\alpha})},\,\mgf{(\toSMT{\alpha})}\bigr]
  =
  \bigl[\lgf{(\toSMT{\alpha})},\,\toSMT{\alpha}\bigr].
\]
The equality uses \(\mgf{(\toSMT{\alpha})}=\toSMT{\alpha}\), observed after \Cref{def:beer-type-encoding}.
In particular, \(\castable{\sigma}{\toSMT{\alpha}}\); by \Cref{cor:castable-constructive}, this yields a cast path \(\mathbb{c}:\castpath{\sigma}{\toSMT{\alpha}}\).

Option-valued functions and their functional graph predicates are equivalent representations: \(\mathsf{optionGraph}\) and \(\mathsf{graphCollapse}\) translate between them and are mutually inverse\footnote{These two identities are formalized by {\leancodeptr{graphCollapse\_optionGraph}{SMT/Reasoning/Representation.html\#graphCollapse_optionGraph}} and {\leancodeptr{optionGraph\_graphCollapse}{SMT/Reasoning/Representation.html\#optionGraph_graphCollapse}}.}.

Decoding an SMT value---first casting it to \(\toSMT{\alpha}\), then applying \(\retr{\alpha}\)---identifies the represented B value, but does not record the representatives needed to inspect that value.
For example, if a set \(X\) is represented by a predicate of type \(\rho\toS\boolS\), a construct that consumes \(X\) binds a target value \(w:\rho\).
The soundness proof must therefore be able to represent every \(x\in X\) by such a \(w\); if \(x\) is itself set-valued, the same requirement recurs inside \(x\).
The following definition isolates exactly this information.

\begin{definition}[Support of a representation][ValueCastAdmissible][SMT/Reasoning/Representation.html\#ValueCastAdmissible]
  \label{def:beer-representation-support}
  Let \(\tau\) be a B type and
  \(
    \sigma\in
    [\lgf{(\toSMT{\tau})},\mgf{(\toSMT{\tau})}]
  \).
  The \emph{support} of \(\sigma\) at \(\tau\) is the set
  \[
    \operatorname{supp}_{\tau}(\sigma)\subseteq\interpZ{\tau}
  \]
  of values representable as \(\tau\)-values in the target representation \(\sigma\).
  At base types it is the whole carrier; at a product type, a pair belongs to the support exactly when its two components belong to the supports of the corresponding component representations.

  It remains to give the set clause.
  For the two possible target representations of a set, we write \(\widehat{\sigma}\) for the \emph{support type}, that is, the SMT type used to represent its members:
  \[
    \widehat{(\rho\toS\boolS)}\triangleq\rho,
    \qquad
    \widehat{(\rho_1\toS\optS\,\rho_2)}
      \triangleq\rho_1\timesS\rho_2.
  \]
  At a set type \(\tau=\setB\alpha\), membership of \(X\in\interpZ{\setB\alpha}\) in the support is given by
  \[
    X\in\operatorname{supp}_{\setB\alpha}(\sigma)
    \quad\Longleftrightarrow\quad
    \exists\mathbb e:\castpath{\widehat{\sigma}}{\toSMT\alpha},\
    \forall x\in X,\
    \exists w\in\interpZ{\widehat{\sigma}},\
    \retr\alpha\bigl(\appZ\zop{\mathbb e}(w)\bigr)=x
    \land
    x\in\operatorname{supp}_{\alpha}(\widehat{\sigma}).
  \]
\end{definition}

In the set case, \(\widehat{\sigma}\) is the target type at which individual members are represented.
A set \(X\) is supported when a single cast path to \(\toSMT{\alpha}\) lets every \(x\in X\) be recovered from some \(w\in\interpZ{\widehat{\sigma}}\).
Requiring \(x\in\operatorname{supp}_{\alpha}(\widehat{\sigma})\) carries the same guarantee recursively into nested set-valued members.

\begin{lemma}[Canonical support][ValueCastAdmissible.canonical][SMT/Reasoning/Representation.html\#ValueCastAdmissible.canonical]
  \label{lem:beer-canonical-support}
  For every B type \(\alpha\), the canonical target type supports every \(\alpha\)-value:
  \[
    \operatorname{supp}_{\alpha}(\toSMT{\alpha})
    =
    \interpZ{\alpha}.
  \]
\end{lemma}

\begin{proof}
  By induction on \(\alpha\).
  The base cases are immediate and products follow componentwise.
  At a set level \(\setB\tau\), choose \(w=\appZ\canon{\tau}(x)\) and use the round-trip law.
\end{proof}

\begin{definition}[Representation-aware agreement][RDomCastAdmissible][SMT/Reasoning/Representation.html\#RDomCastAdmissible]
  \label{def:beer-agreement}
  Let
  \(
    \sigma\in
    [\lgf{(\toSMT{\alpha})},\mgf{(\toSMT{\alpha})}]
  \).
  A B denotation \(\denval{X}[\alpha] : \BDom\) and an SMT denotation \(\denval{Y}[\sigma] : \SDom\) \emph{correspond to each other} (or \emph{agree}), written
  \[
    \denval{X}[\alpha] \;\;{\regnotation{\semrel}}\;\; \denval{Y}[\sigma],
  \]
  if and only if decoding \(Y\) yields \(X\) and \(X\) belongs to the support of \(\sigma\) at \(\alpha\):
  \[
    \left(
      \exists\mathbb{c} : \castpath{\sigma}{\toSMT{\alpha}},\quad
      \retr{\alpha}\bigl(\appZ\zop{\mathbb{c}}(Y)\bigr)=X
    \right)
    \quad\land\quad
    X\in\operatorname{supp}_{\alpha}(\sigma).
  \]
\end{definition}

The two conditions play different roles: the first says \emph{which} B value is represented, whereas support ensures that every part of that value that may later be inspected has a target representative.

By \Cref{lem:beer-canonical-support}, for a canonical representation, \ie when \(\sigma=\toSMT{\alpha}\), agreement reduces extensionally to the equation \(\retr{\alpha}(Y)=X\) used in \Cref{lem:beer-bridge}.
The following lemma generalizes this bridge from canonical images to the representations selected inside the interval.

\begin{lemma}[Membership bridge][setPred\_fapply\_eq\_zftrue\_iff][SMT/Reasoning/Representation.html\#RDomCastSupported.setPred_fapply_eq_zftrue_iff]
  \label{lem:beer-represented-membership}
  Suppose
  \(
    \denval{x}[\alpha] \semrel \denval{w}[\rho]
  \)
  and
  \(
    \denval{S}[\setB\alpha] \semrel
    \denval{F}[\rho \toS \boolS].
  \)
  Then
  \[
    x \in S \iff \appZ F(w)=\topZ.
  \]
\end{lemma}

\begin{proof}
  Use the decoding equations from both agreement hypotheses.
  The characteristic-predicate cast transports \(F\) along the element cast, so its application at the cast of \(w\) is true exactly when the retracted element belongs to the retracted set.
  Substituting the two agreement equations gives the claim.
\end{proof}

Agreement is required only where a term can observe a valuation.
For a B valuation \(\Delta : \mathsf{String} \rightharpoonup \BDom\), an SMT valuation \(\Theta : \mathsf{String} \rightharpoonup \SDom\), and a term \(t\), we say that \(\Delta\) and \(\Theta\) agree on \(t\) if, for every \(v \in \mathsf{fv}(t)\), both valuations are defined at \(v\) and \(\Delta(v) \semrel \Theta(v)\).
No condition is imposed outside \(\mathsf{fv}(t)\).
This is the valuation relation used by \Cref{thm:beer-encodeTerm-spec}.

\begin{definition}[Image valuation][B.RenamingContext.toSMT][SMT/Reasoning/Defs.html\#B.RenamingContext.toSMT]
  \label{def:beer-valuation-image}
  For a B renaming context \(\Delta\), the SMT renaming context \(\toSMT{\Delta}\) is defined variable-by-variable:
  if \(\Delta(v) = \denval{V}[\tau]\) then \(\toSMT{\Delta}(v) \triangleq \denval{\appZ\canon{\tau}(V)}[\toSMT{\tau}]\), and \(\toSMT{\Delta}(v)\) is undefined when \(\Delta(v)\) is.
\end{definition}

\noindent
In the definition above, \(\pf{\toSMT{\tau}}{\appZ\canon{\tau}(V)} : \appZ\canon{\tau}(V) \in \interpZ{\toSMT{\tau}}\) is easily obtained from \(\pf{\tau}{V} : V \in \interpZ{\tau}\): since \(\canon{\tau} \in {\interpZ{\toSMT\tau}}^{\interpZ{\tau}}\) is a total function, function application yields \(\appZ\canon{\tau}(V) \in \interpZ{\toSMT{\tau}}\).

\begin{lemma}[Agreement of image valuations][RValuationCastSupported\_toSMT][SMT/Reasoning/Representation.html\#RValuationCastSupported_toSMT]
  \label{lem:beer-rvaluation-toSMT}
  For any B renaming context \(\Delta\), \(\Delta\) and \(\toSMT{\Delta}\) agree pointwise, and hence agree on every term.
\end{lemma}

\begin{proof}
  At each defined \(v\) with \(\Delta(v) = \denval{V}[\tau]\), the target type is the canonical upper endpoint \(\toSMT{\tau}\), and \(\retr{\tau}(\appZ\canon{\tau}(V)) = V\) by \Cref{thm:beer-round-trip}.
  Support follows by choosing the canonical image of every set member, componentwise through products and nested sets.
\end{proof}

Canonical image valuations are therefore one instance of the theorem's hypothesis, but not the only one.
At the proof-obligation level, the representation context instead selects the concrete types emitted by \beer{}; \Cref{sec:beer-po-soundness} constructs corresponding valuations in both directions: ordinary bindings use canonical representatives, whereas function-selected bindings pass between a functional B graph and the equivalent option-valued SMT function.
