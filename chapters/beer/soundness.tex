\section{Soundness of the encoding}
\label{sec:beer-soundness}

This section states and proves the central term theorem: an encoded term denotes in the representation actually selected by the encoder, and its denotation agrees with the source in the sense of \Cref{def:beer-agreement}.
The proof is carried out by a paired structural induction.
Its ordinary component establishes denotational agreement; its declaration-aware component records enough information about generated helper specifications to replay the argument when a parent construct moves those helpers beneath a binder.
We first state the common invariant, then isolate the shared proof spine and prove the constructor families in groups.

\subsection{The invariant and the theorem}
\label{sec:beer-invariant}

Let \(\Gamma\) be a B typing context and write
\(\Lambda_0\coloneq\toSMT{\Gamma}\) for the initial SMT representation context selected from it.
For a term \(t\), the valuation premise is local: a B valuation \(\Delta\), well formed for \(\Gamma\) in the sense of \Cref{def:b-ren-wf}, and an SMT valuation \(\Theta\) must agree only on \(\mathsf{fv}(t)\), while \(\Theta\) must respect \(\Lambda_0\) there (\Cref{def:beer-valuation-compatibility}).
By \Cref{def:beer-agreement}, agreement with a represented set already supplies a representative for every one of its members at that set representation's bound-value type.
A universal quantifier may, however, select a different representation for its bound names.
If a B domain \(\mathcal D\) contains values of type \(\tau\), the selected binder type is \(\rho\), and \(\mathbb c:\castpath{\rho}{\toSMT{\tau}}\), the required \emph{binder compatibility}, illustrated in \Cref{fig:beer-binder-compatibility}, says that every source value inspected by the binder also has a representative at \(\rho\):

\[

  \exists w\in\interpZ{\rho},\qquad
  \denval{x}[\tau]\;\semrel\;\denval{w}[\rho],

whose decoding equation uses \(\mathbb c\) and whose support component recurses when a bound value contains a set.
When \(\rho\) is the bound-value type already carried by the represented domain, its support supplies these witnesses; at the canonical representation one may take \(w=\appZ\canon{\tau}(x)\).

\begin{theorem}[Representation-aware soundness of term encoding][encodeTerm\_rep\_spec][SMT/Reasoning/EncodeTermRepresented.html\#encodeTerm_rep_spec]
  \label{thm:beer-encodeTerm-spec}
  Let \(t\) be a well-typed, well-defined B term, \ie
  \(\btype{\Gamma}{t}{\alpha}\), and \(\WD(t)\).
  Assume that the binder-compatibility condition above holds for every bounded universal occurring in \(t\).

  Let \(\Delta\) be a B valuation well formed for \(\Gamma\) (\Cref{def:b-ren-wf}), and let \(\Theta_0\) be an SMT valuation that agrees with \(\Delta\) on \(\mathsf{fv}(t)\) and respects \(\Lambda_0\) there (\Cref{def:beer-valuation-compatibility}).
  Suppose that an encoder run initialized with \(\Lambda_0\) satisfies
  \[
    \interpB{\aterm{t}{\Delta}}=\denval{T}[\alpha]
    \qquad\text{and}\qquad
    t \encto (t',\sigma).
  \]
  Write \(\Lambda'\) for the output type context of this run.
  It extends \(\Lambda_0\) with the declarations of the fresh helper variables generated while encoding \(t\).
  Then:
  \begin{enumerate}
    \item \emph{Type correctness modulo loosening.}
      The result type satisfies
      \(\sigma\in[\lgf{(\toSMT{\alpha})},\mgf{(\toSMT{\alpha})}]\), a cast path \(\mathbb c:\castpath{\sigma}{\toSMT{\alpha}}\) exists, and \(\stype{\Lambda'}{t'}{\sigma}\).
    \item \emph{Semantic agreement.}
      There is an SMT valuation \(\Theta'\) extending \(\Theta_0\) to the generated helper variables and a denotation \(\denval{T'}[\sigma]\) such that
    \[
      \interpS{\aterm{t'}{\Theta'}}=\denval{T'}[\sigma]
      \qquad\text{and}\qquad
      \denval{T}[\alpha]\;\semrel\;\denval{T'}[\sigma].
    \]
    \item \emph{Valuation stability.}
      For every other well-formed B valuation \(\Delta_a\) and SMT valuation \(\Theta_a\) satisfying the same free-variable agreement and context conditions, if \(t\) denotes \(\denval{T_a}[\alpha]\) under \(\Delta_a\), then \(\Theta_a\) extends to a valuation under which the same emitted term \(t'\) denotes some \(\denval{T_a'}[\sigma]\) with
      \(\denval{T_a}[\alpha]\semrel\denval{T_a'}[\sigma]\).
  \end{enumerate}
\end{theorem}

The proof component of the target triple \(\denval{T'}[\sigma]\) is constructed from target typing and denotation: \(\stype{\Lambda'}{t'}{\sigma}\), together with the fact that \(t'\) is denoted by \(T'\), yields \(T'\in\interpZ{\sigma}\) by type determinacy.
It is therefore part of the conclusion, not an additional semantic premise.

Valuation stability is the totality strengthening needed beneath binders: the same emitted term remains correct for every admissible pair of source and target valuations, not only for the initial pair \((\Delta,\Theta_0)\).
By \Cref{lem:beer-rvaluation-toSMT}, the canonical image valuation of \Cref{def:beer-valuation-image} is one admissible choice for \(\Theta_0\).
Complete proof obligation encoding may instead assign an option-valued function representation to a source relation known to be functional; in that case, \Cref{sec:beer-po-soundness} constructs the corresponding target value by collapsing its graph into a functional representation, and the resulting valuations satisfy the same agreement premise.
\Cref{fig:beer-semantic-square} summarizes this relation independently of how the target valuation is constructed.

For formulas, the general relation specializes to literal equality.

\begin{corollary}[Boolean soundness][encodeTerm\_rep\_bool\_spec][SMT/Reasoning/EncodeTermRepresented.html\#encodeTerm_rep_bool_spec]
  \label{cor:beer-encodeTerm-bool-spec}
  Under the hypotheses of \Cref{thm:beer-encodeTerm-spec}, if \(t\) has B type \(\boolB\), then \(\sigma=\boolS\) and
  \[
    \interpB{\aterm{t}{\Delta}}=\denval{b}[\boolB]
    \quad\Longleftrightarrow\quad
    \interpS{\aterm{t'}{\Theta'}}=\denval{b}[\boolS]
    \qquad (b\in\Zbool).
  \]
\end{corollary}

\begin{proof}
  At Boolean type the interval is the singleton \([\boolS,\boolS]\), so \(\sigma=\boolS\).
  The cast is therefore reflexive and \(\retr{\boolB}\) is the identity, so agreement is equality of the two ZF Boolean values.
\end{proof}

Every hypothesis and goal in a proof obligation is a formula, and therefore has B type \(\boolB\).
The corollary thus applies directly to each of them and shows that its truth value is both preserved and reflected by the encoding.
Together with the corresponding valuation constructions, this is the term-level result used in \Cref{sec:beer-po-soundness} to relate countermodels of a complete obligation to models of its SMT refutation script.

The induction uses the same few semantic facts in every constructor; \Cref{tab:beer-spine} records their roles.
Besides the lemmas established in \Cref{sec:beer-semantic-bridge}, it uses exactness of semantic loosening (\Cref{thm:loosening-correctness}), the standard substitution lemma under binders, and totality and type determinacy of the B and SMT denotations (\Cref{thm:b-denote-complete,thm:b-denote-type-det,thm:smt-denote-complete,thm:smt-denote-type-det}).

It is useful to read each induction branch as establishing three synchronized invariants.
First, the encoding rule fixes the shape of the selected interval member \(\sigma\), constructs its cast to \(\toSMT{\alpha}\), and derives \(\stype{\Lambda'}{t'}{\sigma}\).
Second, totality supplies a target value \(T'\) under the extended valuation, while type determinacy places \(T'\) in \(\interpZ{\sigma}\).
Third, a constructor-specific semantic equation proves that \(T'\) decodes to the source value \(T\), and a support argument provides representatives for every nested value that a later constructor may inspect.
The valuation-stability clause repeats these three steps for an arbitrary admissible pair \((\Delta_a,\Theta_a)\); the emitted term and selected type stay fixed, and only the denotations and the values assigned to generated helpers vary.
It is therefore not a second semantic calculation: the constructor equation is proved once with the admissible valuations kept arbitrary.
Helper-generating branches use the scoped helper contract; the others reuse \(\Theta_a\).

Set-valued cases discharge the third invariant by a two-sided pointwise
argument, after applying the semantic casts selected by the representation.
Let \(S\in\interpZ{\setB\alpha}\), let
\(F\in\interpZ{\sigma\toS\boolS}\), and suppose that \(\sigma\) is a
supported representation of \(\alpha\).
To establish
\[
  \denval{S}[\setB\alpha]\;\semrel\;
  \denval{F}[\sigma\toS\boolS],
\]
the pointwise construction used in the proof has exactly two obligations:
\[
  \begin{aligned}
    F(w)=\topZ
    &\Longrightarrow
      \exists x\in S,\,
      \denval{x}[\alpha]\;\semrel\;\denval{w}[\sigma]
      &&\text{for every \(w\in\interpZ{\sigma}\)},\\
    x\in S
    &\Longrightarrow
      \exists w\in\interpZ{\sigma},\,
      \denval{x}[\alpha]\;\semrel\;\denval{w}[\sigma]
      \ \land\ F(w)=\topZ
      &&\text{for every \(x\in\interpZ{\alpha}\)}.
  \end{aligned}
\]
The first excludes a target point accepted without a corresponding source
member; the second supplies a true supported representative for each source
member.
Once the agreement has been established,
\Cref{lem:beer-represented-membership} gives the pointwise equivalence
\[
  \denval{x}[\alpha]\semrel\denval{w}[\sigma]
  \quad\Longrightarrow\quad
  \bigl(F(w)=\topZ\iff x\in S\bigr).
\]

Now let \(R\in\interpZ{\setB(\alpha\prodB\beta)}\) and let
\(F\in\interpZ{\sigma\toS\optS\tau}\), where \(\sigma\) and \(\tau\)
are supported representations of \(\alpha\) and \(\beta\), respectively.
Suppose
\[
  \denval{R}[\setB(\alpha\prodB\beta)]
  \;\semrel\;
  \denval{F}[\sigma\toS\optS\tau].
\]
For related arguments and results, the option-valued function application law is
\[
  \denval{x}[\alpha]\;\semrel\;\denval{a}[\sigma]
  \;\land\;
  \denval{y}[\beta]\;\semrel\;\denval{b}[\tau]
  \quad\Longrightarrow\quad
  \bigl(F(a)=\someZ b\iff\pairZ{x}{y}\in R\bigr).
\]
Its proof casts \(F\) to the corresponding characteristic predicate and
applies the membership bridge at the represented pair.
This is the pointwise fact used by the intersection and application
cases below.

The other recurring comparison concerns target equality after two represented values have been reconciled to a common type.
The following formal result, illustrated in
\Cref{fig:beer-represented-equality}, is used by the equality case and by the
equality tests inside the product and partial-function encodings.

\begin{lemma}[Equality of represented values][RDomCastSupported.cast\_eq\_iff][SMT/Reasoning/Representation.html\#RDomCastSupported.cast_eq_iff]
  \label{lem:beer-represented-equality}
  Suppose
  \[
    \denval{X}[\alpha]\semrel\denval{A}[\sigma],
    \qquad
    \denval{Y}[\alpha]\semrel\denval{B}[\tau],
  \]
  and let \(\mathbb c:\castpath{\sigma}{\tau}\).
  Then
  \[
    \appZ\zop{\mathbb c}(A)=B
    \quad\Longleftrightarrow\quad
    X=Y.
  \]
\end{lemma}

\begin{proof}
  We proceed by structural induction on \(\alpha\), keeping both supported
  representations and the cast path general.
  Write
  \(
    \widehat A\coloneq\appZ\zop{\mathbb c}(A)
  \).

  \emph{Atomic types.}
  If \(\alpha\) is \(\intB\) or \(\boolB\), its representation interval is a
  singleton.
  Thus both target values use the canonical representation, the cast is
  semantically the identity, and the two agreement equations give
  \[
    \widehat A=B
    \quad\Longleftrightarrow\quad
    \appZ\retr{\alpha}(\widehat A)
      =\appZ\retr{\alpha}(B)
    \quad\Longleftrightarrow\quad
    X=Y.
  \]

  \emph{Products.}
  Suppose \(\alpha=\alpha_1\prodB\alpha_2\).
  Supported representations then force
  \(A=\pairZ{A_1}{A_2}\), \(B=\pairZ{B_1}{B_2}\), and a componentwise cast
  \(\mathbb c=(\mathbb c_1,\mathbb c_2)\).
  Writing \(X=\pairZ{X_1}{X_2}\) and
  \(Y=\pairZ{Y_1}{Y_2}\), injectivity of pairing and the two induction
  hypotheses yield
  \[
    \begin{aligned}
      \widehat A=B
      &\iff
        \appZ\zop{\mathbb c_1}(A_1)=B_1
        \ \land\
        \appZ\zop{\mathbb c_2}(A_2)=B_2\\
      &\iff X_1=Y_1\ \land\ X_2=Y_2\\
      &\iff X=Y.
    \end{aligned}
  \]

  \emph{Characteristic predicates.}
  Consider \(\alpha=\setB\beta\).
  Suppose first that \(A\) and \(B\) are characteristic predicates, and let
  \(\mathbb{p}\) be the induced cast between their argument representations.
  If \(\widehat A=B\) and \(x\in X\), support supplies an \(a\) representing
  \(x\) with \(A(a)=\topZ\).
  The cast point \(b=\appZ\zop{\mathbb{p}}(a)\) still represents \(x\) by the induction
  hypothesis, and the definition of the predicate cast gives
  \(\widehat A(b)=\topZ\).
  Hence, \(B(b)=\topZ\), and
  \Cref{lem:beer-represented-membership} yields \(x\in Y\).
  The converse inclusion uses a supported representative supplied by \(B\)
  and the preimage property of the cast; therefore
  \(\widehat A=B\) implies \(X=Y\).

  Conversely, assume \(X=Y\).
  Whenever either predicate is true at a target argument \(b\), the cast
  preimage and support conditions provide a source value \(x_b\) represented
  at that point.
  Applying \Cref{lem:beer-represented-membership} on both sides gives
  \[
    \widehat A(b)=\topZ
    \quad\Longleftrightarrow\quad
    x_b\in X
    \quad\Longleftrightarrow\quad
    x_b\in Y
    \quad\Longleftrightarrow\quad
    B(b)=\topZ.
  \]
  Since both results are ZF Booleans, equality of their true cases is
  pointwise equality; function extensionality concludes
  \(\widehat A=B\).

  \emph{Option-valued functions.}
  The remaining supported set representation occurs when
  \(\beta=\beta_1\prodB\beta_2\).
  If \(A\) is option-valued and \(B\) is a characteristic predicate, the cast
  replaces \(A\) by its predicate graph.
  At a represented pair \(\pairZ{a}{b}\), its defining equation is
  \[
    \mathsf{graph}_{\mathbb c}(A)
      \bigl(\pairZ{\appZ\zop{\mathbb c_1}(a)}
                    {\appZ\zop{\mathbb c_2}(b)}\bigr)=\topZ
    \quad\Longleftrightarrow\quad
    A(a)=\someZ b.
  \]
  The product induction hypothesis identifies the represented pair on both
  sides, so the characteristic predicate case proves graph equality exactly
  when \(X=Y\).

  Finally, suppose that both \(A\) and \(B\) are option-valued.
  Let \(\mathsf G(F)\) denote the characteristic predicate graph of \(F\).
  Graph representation commutes with the endpoint casts, and the preceding case therefore
  gives
  \[
    \mathsf G(\widehat A)=\mathsf G(B)
    \quad\Longleftrightarrow\quad
    X=Y.
  \]
  The forward implication from \(\widehat A=B\) follows by congruence.
  Conversely, equality of the two graphs implies
  \(\widehat A=B\) because the option-graph translation is injective on
  well-typed option-valued functions.
  Hence \(\widehat A=B\) if and only if \(X=Y\), completing the induction.
\end{proof}

The interval invariant fixes the atomic shapes: the intervals associated with \(\intB\) and \(\boolB\) are singletons.
The encoding rules preserve the remaining constructor shapes: a product is represented by a product of the component representations, while a set is represented by a characteristic predicate or, when its functional structure is retained, by an option-valued function whose endpoint types recursively represent the corresponding B types.
Each encoder case therefore has exactly the semantic shapes its implementation inspects.

\subsection{Homomorphic cases}
\label{sec:beer-case-homomorphic}

For a variable \(v\), the emitted term is the same variable.
Its target denotation is \(\Theta_0(v)\), and the valuation hypothesis already states
\[
  \interpB{\aterm{v}{\Delta}}
  \;=\;\Delta(v)
  \;\semrel\;
  \Theta_0(v)
  \;=\;\interpS{\aterm{v}{\Theta_0}};
\]
no canonicalization of the assignment is required.
This is the base case from which arbitrary selected representations enter the induction.

Integer and Boolean literals use the same ZF encodings in both languages, and their singleton intervals force the target types to \(\intS\) and \(\boolS\).
Thus their denotations agree by reflexivity.
For a B arithmetic, order, or logical operator \(\bop{\odot}\) whose encoding
uses the corresponding SMT operator \(\sop{\odot}\), write \(X_i\) and
\(X_i'\) for the related source and target operand values, respectively.
The atomic representations are identities, hence
\[
  \interpS{\aterm{\sop{\odot}(t_1',\ldots,t_n')}{\Theta'}}
  \;=\;\odot^{\mathsf Z}(X_1',\ldots,X_n')
  \;=\;\odot^{\mathsf Z}(X_1,\ldots,X_n)
  \;=\;\interpB{\aterm{\bop{\odot}(t_1,\ldots,t_n)}{\Delta}}.
\]
This covers integer addition, subtraction and multiplication, integer order, Boolean conjunction and negation, and the atomic instances of equality.
For a maplet, the target is a pair of the two recursively produced denotations; interval membership and support are componentwise, and the product semantic cast commutes with pairing.
Consequently,
\[
  \denval{\pairZ{X}{Y}}[\alpha\prodB\beta]
  \;\semrel\;
  \denval{\pairZ{X'}{Y'}}[\sigma\timesS\tau].
\]

The base sets \(\ZintB\) and \(\ZboolB\) produce constant-true predicates.
For example, if \(F=\lamZ w \mapsto \topZ \in {\Zbool}^{\Zint}\), then
\[
  \retr{\setB\intB}(F)
  =\{z\in\Zint\mid F(z)=\topZ\}
  =\Zint,
\]
and every integer is its own support witness.
The Boolean case is identical.

\subsection{Pointwise set operations}
\label{sec:beer-case-pointwise}

Union is the representative non-homomorphic case because its operands may occupy different points of the same representation interval.
Let its two operands have the common B type \(\setB\alpha\), with source
denotations \(\mathcal A,\mathcal B\).
The induction hypotheses provide target denotations
\(F\in\interpZ{\rho_A}\) and \(G\in\interpZ{\rho_B}\) satisfying
\[
  \denval{\mathcal A}[\setB\alpha]\;\semrel\;\denval{F}[\rho_A],
  \qquad
  \denval{\mathcal B}[\setB\alpha]\;\semrel\;\denval{G}[\rho_B].
\]
The \encruleref{rule:beer-union} rule selects an element representation
\[
  \kappa\in
  [\lgf{(\toSMT{\alpha})},\mgf{(\toSMT{\alpha})}]
\]
and reconciles both operands to the common characteristic-predicate type
\(\kappa\toS\boolS\).
Write \(\bar F,\bar G\) for the denotations of the reconciled terms.
The exactness conclusion of \Cref{thm:loosening-correctness} gives the explicit
relations
\[
  \denval{\mathcal A}[\setB\alpha]
    \;\semrel\;\denval{\bar F}[\kappa\toS\boolS],
  \qquad
  \denval{\mathcal B}[\setB\alpha]
    \;\semrel\;\denval{\bar G}[\kappa\toS\boolS].
\]
The emitted predicate \(U\) is such that for every \(w\in\interpZ{\kappa}\),
\[
  U(w)=\bar F(w)\mathbin{\zop{\lor}}\bar G(w).
\]
For every
\(\denval{x}[\alpha]\;\semrel\;\denval{w}[\kappa]\),
\Cref{lem:beer-represented-membership} gives
\[
  \begin{aligned}
    U(w)=\topZ
    &\iff \bar F(w)=\topZ\ \lor\ \bar G(w)=\topZ\\
    &\iff x\in\mathcal A\ \lor\ x\in\mathcal B\\
    &\iff x\in\mathcal A\cup\mathcal B.
  \end{aligned}
\]
Conversely, a member of the union belongs to one operand, whose support supplies a representative on which the corresponding predicate, and hence \(U\), is true.
The two-sided pointwise argument therefore yields
\[
  \denval{\mathcal A\cup\mathcal B}[\setB\alpha]
  \;\semrel\;
  \denval{U}[\kappa\toS\boolS].
\]
If an operand is option-valued, reconciliation first replaces it by its option graph.
The inverse graph equations mentioned in \Cref{sec:beer-agreement} show that this changes only the representation, not the B relation, so the same calculation applies.

The relational branch of intersection is the dual calculation:
\[
  I(w)=\topZ
  \iff \bar F(w)=\topZ\land\bar G(w)=\topZ
  \iff x\in\mathcal A\cap\mathcal B.
\]
A source member now belongs to both operands; either support witness can be transported to the common representation by loosening exactness, and the membership bridge makes both conjuncts true there.

For the functional branch, specialize the common B type to
\(\setB(\alpha\prodB\beta)\) and suppose that both source relations
\(\mathcal A,\mathcal B\) are functional.
The \encruleref{rule:beer-intersection} rule reconciles their target
representations to a common option-valued function type
\(\kappa\toS\optS\lambda\), where \(\kappa\) and \(\lambda\) are supported
representations of \(\alpha\) and \(\beta\), respectively.
Writing \(\bar F,\bar G\) for the resulting denotations, loosening exactness
gives
\[
  \begin{aligned}
    \denval{\mathcal A}[\setB(\alpha\prodB\beta)]
      &\;\semrel\;\denval{\bar F}[\kappa\toS\optS\lambda],\\
    \denval{\mathcal B}[\setB(\alpha\prodB\beta)]
      &\;\semrel\;\denval{\bar G}[\kappa\toS\optS\lambda].
  \end{aligned}
\]
The rule then emits
\[
  H(a) =
  \begin{cases}
    \bar F(a), & \text{if } \bar F(a)=\bar G(a),\\
    \noneZ, & \text{otherwise}.
  \end{cases}
\]
For every \(x,y,a,b\) such that
\[
  \denval{x}[\alpha]\;\semrel\;\denval{a}[\kappa],
  \qquad
  \denval{y}[\beta]\;\semrel\;\denval{b}[\lambda],
\]
the option-valued function criterion gives
\[
  \begin{aligned}
    H(a)=\someZ b
    &\iff
    \bar F(a)=\someZ b \land \bar G(a)=\someZ b\\
    &\iff
    (x,y)\in\mathcal A\land(x,y)\in\mathcal B\\
    &\iff
    (x,y)\in\mathcal A\cap\mathcal B.
  \end{aligned}
\]
The forward implication decodes an emitted option value into a maplet belonging to both source relations.
For the reverse implication, support supplies representatives \(a,b\) of any
maplet \((x,y)\) in the source intersection; both reconciled functions return
the same result representative \(b\), so \(H\) returns it as well.
The option-valued function version of the pointwise argument proves agreement with the source intersection.

If the two selected option-valued function types already coincide, reconciliation is
reflexive and introduces no loosening helper.
If either selected type is strictly tighter than the common endpoint,
exactness of loosening transfers its denotation to that endpoint, and the
generated specification enforces the transfer under every satisfying helper
valuation.
Consequently, the equivalence for \(H(a)=\someZ b\) above proves ordinary
agreement; because it holds for every valuation satisfying the helper
specification, it also proves the declaration-aware clause.

For membership, recursive encoding and the cast function arrange an element and a set at compatible representations.
If the set is a predicate, \Cref{lem:beer-represented-membership} immediately equates the emitted application with B membership.
If it is option-valued, membership is the equation \(F(x)=\someZ y\); the option-graph equivalence turns this into membership of \((x,y)\) in the represented B relation.
Both branches return \(\boolS\), so \Cref{cor:beer-encodeTerm-bool-spec} identifies the resulting truth value.

For equality, the encoder first casts one operand to the other's type or both to a common type.
\Cref{lem:beer-represented-equality} states precisely that equality after the selected cast holds if and only if the represented B values are equal.
The emitted Boolean therefore has exactly the source equality's truth value.

\subsection{Application}
\label{sec:beer-case-application}

Let \(t \coloneq \appB f\ x\).
Well-definedness gives the semantic facts needed by this case: the B denotation \(F\) of \(f\) is functional, the denotation \(X\) of \(x\) lies in its domain, and the source result is the unique \(Y\) with \((X,Y)\in F\).

The \encruleref{rule:beer-application} rule reconciles the argument and the function domain, then applies the resulting function-valued view \(f^{\mathrm{fun}}\).
If the target representation of \(f\) is already option-valued, \Cref{thm:loosening-correctness} preserves its option graph.
If it is a graph predicate \(f^{\mathrm{rel}}\), the generated
graph-equivalence specification requires every satisfying
\(f^{\mathrm{fun}}\) to have the same graph as \(f^{\mathrm{rel}}\).
Since \(F\) is functional, the inverse graph equations of
\Cref{sec:beer-agreement} show that this changes only its representation.

Write \(\beta\) for the source result type and \(\rho\) for its selected target representation, and let \(X'\) be the reconciled target argument.
The pointwise option criterion now gives
\[
  f^{\mathrm{fun}}(X')=\someZ Y'
  \quad\Longleftrightarrow\quad
  (X,Y)\in F
\]
for some \(Y'\) representing \(Y\).
Existence follows from \(X\in\Dom(F)\), while source functionality makes the decoded \(Y\) unique.
Thus the option cannot be \(\noneZ\), and
\[
  \mathsf{the}\bigl(f^{\mathrm{fun}}(X')\bigr)=Y'
  \qquad\text{with}\qquad
  \denval{Y}[\beta]\;\semrel\;\denval{Y'}[\rho].
\]
The same equations hold for every satisfying assignment to the generated graph helper, which proves the declaration-aware clause as well.

\subsection{Set formers}
\label{sec:beer-case-set-formers}

Powerset, Cartesian product, and partial-function space emit characteristic predicates.
Their proofs retain the same set-theoretic core as in the canonical case; the difference is that instantiation points now come from the support carried by agreement rather than being assumed to be canonical images.

For \(\powB(S)\), let \(T\) be a candidate source set and \(E\) a related target representation.
After normalizing \(E\) and the representation \(F\) of \(S\) to predicates at a common element type, the emitted predicate \(\Pi\) satisfies
\[
  \begin{aligned}
    \Pi(E)=\topZ
    &\iff
      \forall w,\ E(w)=\topZ\Rightarrow F(w)=\topZ\\
    &\iff
      \forall x,\ x\in T\Rightarrow x\in S\\
    &\iff T\subseteq S.
  \end{aligned}
\]
For the middle equivalence, a true target application decodes through \Cref{lem:beer-represented-membership}; in the reverse direction, support supplies a representative of every \(x\in T\).
Thus \(\Pi\) is true exactly on the members of \(\powB(S)\), and candidate-set support gives the reverse direction required for agreement.

For \(A\prodB B\), let \(C\) be the emitted predicate and let \(z\) represent a source pair \(\pairZ{x}{y}\).
The \encruleref{rule:beer-cartesian-product} rule and the two membership bridges give
\[
  \begin{aligned}
    C(z)=\topZ
    &\iff
      \exists a,b,\,
      F_A(a)=\topZ\;\land\; F_B(b)=\topZ
      \;\land\; z=\pairZ{a}{b}\\
    &\iff x\in A\;\land\; y\in B\\
    &\iff \pairZ{x}{y}\in A\times B.
  \end{aligned}
\]
The equality conjunct is reflected by \Cref{lem:beer-represented-equality}.
Conversely, support supplies \(a,b\) for any source pair in \(A\times B\), and their target pair witnesses the existential.

For \(A\pfunB B\), let \(R\) be the relation decoded from a candidate target predicate.
The first conjunct emitted by \encruleref{rule:beer-partial-function-space} is the Cartesian-product test above; the second says that any two represented pairs with equal first components have equal second components.
By \Cref{lem:beer-represented-equality},
\[
  \begin{aligned}
    Q(R)=\topZ
    &\iff
      R\subseteq A\times B
      \;\land\;
      \left(\forall x,y_1,y_2,\,
        (x,y_1)\in R\land(x,y_2)\in R\;\implies\; y_1=y_2\right)\\
    &\iff R\in A\pfunB B.
  \end{aligned}
\]
The forward direction decodes the quantified target pairs.
For the reverse direction, support represents the source pairs and source functionality supplies the equality demanded by the target formula.
Hence the emitted characteristic predicate agrees with the B partial-function space.

\subsection{Comprehension and lambdas}
\label{sec:beer-case-comprehension}

For a comprehension \(\bcomp{\vec{\var{v}}\inB D}{P}\), write \(\mathcal D\) for the source domain, \(G\) for its reconciled target predicate, and \(P_x\) and \(P'_w\) for the source and target body values under related tuple assignments
\(\denval{x}[\tau]\;\semrel\;\denval{w}[\rho]\).
For a tuple \(u\in\mathcal D\), write \(\vec{u}\) for the ordered components obtained by destructuring its left-associated product.
The \encruleref{rule:beer-comprehension} rule emits a predicate \(C\) with
\[
  \begin{aligned}
    C(w)=\topZ
    &\iff G(w)=\topZ\land P'_w=\topZ\\
    &\iff x\in\mathcal D\land P_x=\topZ\\
    &\iff
      x\in
      \{u\in\mathcal D\mid
        \interpB{\aterm{P[\vec{\var{v}}\leftarrow\vec{u}]}{\Delta}}=\topZ\}.
  \end{aligned}
\]
The first equivalence is the denotation of the guarded target predicate.
For the second, \Cref{lem:beer-represented-membership} handles the guard; the substitution lemma identifies the two extended valuations, and the Boolean induction hypothesis identifies the body truth values.
If \(x\) belongs to the source comprehension, support of \(\mathcal D\) provides \(w\), so the reverse pointwise condition also holds.
The two-sided pointwise argument therefore proves agreement with the B separation denotation.

The lambda case uses the same tuple transport, but the \encruleref{rule:beer-lambda} rule emits an option-valued function \(L\).
Write \(F'_a\) for the target body value under the tuple assignment \(a\).
For
\(\denval{x}[\tau]\;\semrel\;\denval{a}[\rho]\)
and
\(\denval{p}[\beta]\;\semrel\;\denval{b}[\sigma]\),
\[
  \begin{aligned}
    L(a)=\someZ b
    &\iff G(a)=\topZ\land F'_a=b\\
    &\iff x\in\mathcal D\land
      p=\interpB{\aterm{P[\vec{\var{v}}\leftarrow\vec{x}]}{\Delta}}\\
    &\iff
      (x,p)\in
      \{(u,\interpB{\aterm{P[\vec{\var{v}}\leftarrow\vec{u}]}{\Delta}})
        \mid u\in\mathcal D\}.
  \end{aligned}
\]
The forward direction decodes any defined target application into a source maplet.
Conversely, support supplies a representative \(a\) of every \(x\in\mathcal D\), and the body induction hypothesis supplies a related \(b\); the guard is true and \(L(a)=\someZ b\).
The option-valued function version of the pointwise argument proves agreement with the B lambda graph.

In both cases the body is interpreted under the bound tuple.
The declaration-aware induction hypothesis makes both the calculation of
\(C(w)\) for comprehension and that of \(L(a)\) for lambda valid for every
typed assignment satisfying the helper specifications.
This proves the required stability rather than correctness for only one chosen
evaluation.

\subsection{The universal quantifier}
\label{sec:beer-case-forall}

The universal case \(\forallB \vec{\var{v}} \inB D \cdot P\) combines binder compatibility, scoped helpers, and valuation stability.
Let \((U',\boolS)\) be the output of the \encruleref{rule:beer-bounded-universal} rule, and define
\begin{align*}
  \denval{U_{\mathsf B}}[\boolB][\irrelprf] &\coloneq \interpB{\aterm{\forallB \vec{\var{v}} \inB D \cdot P}{\Delta}},\quad
  \denval{\mathcal D}[\setB \tau][\irrelprf] \coloneq \interpB{\aterm{D}{\Delta}},\\
  \denval{U_{\mathsf S}}[\boolS][\irrelprf] &\coloneq \interpS{\aterm{U'}{\Theta'}}.
\end{align*}
For \(x\in\mathcal D\), write \(P_x\) for the source body value under the tuple \(x\):
\[
  \forall x\in\mathcal D,\,
  \denval{P_x}[\boolB][\irrelprf] \coloneq
  \interpB{\aterm{P[\vec{\var{v}}\leftarrow\vec{x}]}{\Delta}}.
\]
The encoding introduces local helper variables \(h_1,\cdots,h_k\).
For a typed target tuple \(w\) and a typed helper assignment \(\vec{h}=\langle h_1,\cdots,h_k\rangle\), write \(G_{w,\vec{h}}\) and \(P'_{w,\vec{h}}\) for the values of the encoded membership guard and body under the valuation extended by \(w\) and \(\vec{h}\).
Finally, \(\mathsf{Spec}_w(\vec{h})\) means that every generated helper specification has value \(\topZ\) under this same valuation.
The B and SMT truth conditions are
\[
  \begin{aligned}
    U_{\mathsf B}=\topZ
    &\iff \forall x\in\mathcal D,\ P_x=\topZ,\\
    U_{\mathsf S}=\topZ
    &\iff
      \forall w,\vec{h},\,
      \mathsf{Spec}_w(\vec{h})\implies
      G_{w,\vec{h}}=\topZ\implies P'_{w,\vec{h}}=\topZ.
  \end{aligned}
\]
The second equivalence is obtained by repeatedly using the Boolean law
\[
  (H_1\Rightarrow\cdots\Rightarrow H_k\Rightarrow Q)=\topZ
  \iff
  \bigl(H_1=\cdots=H_k=\topZ\bigr)\Rightarrow Q=\topZ
\]
for the helper specifications generated by \encruleref{rule:beer-bounded-universal}.

Assume first that \(U_{\mathsf B}=\topZ\), and choose arbitrary typed \(w,\vec{h}\) satisfying \(\mathsf{Spec}_w(\vec{h})\).
If \(G_{w,\vec{h}}=\botZ\), the implication is true.
If \(G_{w,\vec{h}}=\topZ\), \Cref{lem:beer-represented-membership} decodes \(w\) to some \(x\in\mathcal D\).
The source universal gives \(P_x=\topZ\), and the substitution lemma together with the declaration-aware Boolean induction hypothesis gives
\[
  P'_{w,\vec{h}}=P_x=\topZ.
\]
Thus, \(U_{\mathsf S}=\topZ\).

Conversely, assume \(U_{\mathsf S}=\topZ\) and choose \(x\in\mathcal D\).
Binder compatibility supplies a target tuple \(w\) whose cast and retraction is \(x\).
The declaration-aware induction hypotheses and exactness of loosening (\Cref{thm:loosening-correctness}) supply a typed helper assignment \(\vec{h}\) satisfying \(\mathsf{Spec}_w(\vec{h})\).
Under this assignment, the membership bridge gives \(G_{w,\vec{h}}=\topZ\), so target truth yields \(P'_{w,\vec{h}}=\topZ\).
Valuation stability then reflects this through the body induction hypothesis to \(P_x=\topZ\).
Hence \(U_{\mathsf B}=\topZ\).
When \(\mathcal D=\varnothing\), the same argument is vacuous: every target guard is false and both universals are true.

This proves the universal case at every selected binder type admitted by the compatibility premise.
Usually, the recursive support of the represented domain supplies the required preimages.
For an option-valued function binder over a semantically functional relation,
the correspondence between its predicate and option-valued representations
supplies the required preimage instead.
\Cref{sec:beer-po-soundness} records how proof-obligation encoding establishes these alternatives.

\subsection{Completion of the induction.}
The preceding calculations cover every constructor on which encoding succeeds.
In each case, the encoding rule and the induction hypotheses also establish the \emph{type correctness modulo loosening} clause of \Cref{thm:beer-encodeTerm-spec}.
Target denotational completeness supplies the denotation \(T'\), while the displayed decoding equation and support argument establish \emph{semantic agreement}.
Running the same case proof with the declaration-aware induction hypotheses makes each calculation independent of the chosen satisfying helper valuation, which gives \emph{valuation stability}.
This concludes the proof of \Cref{thm:beer-encodeTerm-spec}.
